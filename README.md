# LensMovie

A Python CLI application.

## Requirements

- Python 3.9+

## Installation

```bash
pip install -e .
```

To include development dependencies:

```bash
pip install -e ".[dev]"
```

## Usage

```bash
lensmovie
# Hello from LensMovie!

lensmovie --version
# lensmovie 0.1.0
```

## Development

Run the tests:

```bash
pytest
```

## Project Structure

```
src/lensmovie/        # Application package
tests/                # Test suite
```
